# Sideways ROM types

The BBC Micro's sideways ROM mechanism assumes each ROM is up to 16 KB
in size, and so most sideways ROM images are single files of 16 KB or
smaller. But there were some ROMs produced that got around this limit
with extra hardware.

To use one of these ROMs with b2, use the `Type` submenu to select the
appropriate type, according to the ROM in question.

## `16 KB`

Ordinary single ROM image, 16 KB or smaller.

## `Inter-Word (32 KB)`

- Computer Concepts Inter-Word
- AMX Design
- Beebug Master ROM

## `Inter-Base (64 KB)`

- Computer Concepts Inter-Base
- PMS The Publisher

## `Spellmaster (128 KB)`

- Computer Concepts Spellmaster
- Computer Concepts Mega3

## `Quest Paint (32 KB)`

- Watford Quest Paint
- Watford ConQuest
- Watford PCB Designer

## `Wapping Editor (64 KB)`

- The Wapping Editor

## `TED (32 KB)`

- Watford TED (Teletext Editor)

## `PRES ABE+ (32 KB)`

- PRES Advanced BASIC Editor Plus

## `PRES ABE (32 KB)`

- PRES Advanced BASIC Editor

## `View Trilogy (64 KB)`

- Acornsoft View Trilogy (see https://stardot.org.uk/forums/viewtopic.php?t=25960)
