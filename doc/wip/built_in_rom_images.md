# Built-in ROM images

b2 comes with a number of built-in ROM images, corresponding to the
various ROMs that the default configurations use.

## B

OS ROM:

- `OS 1.20` - OS 1.20

BASIC ROM:

- `BASIC II` - BASIC II

DFS ROMs one for each type of disk interfaces:

- `Acorn 1770 DFS` - for use with `Acorn 1770`
- `Watford DDFS (DDB2)` - for use with `Watford 1770 (DDB2)`
- `Watford DDFS (DDB3)` - for use with `Watford 1770 (DDB3)`
- `Opus DDOS` - for use with `Opus 1770`
- `Opus Challenger` - for use with `Opus CHALLENGER 256k` or `Opus
  CHALLENGER 512k`

## B+

OS ROM:

- `B+ MOS` - OS 2.00

BASIC ROM:

- `BASIC II` - BASIC II

DFS ROM:

- `Acorn 1770 DFS`

## Master 128

There's two sets of ROMs, for the two released versions of the OS: MOS
3.20 and MOS 3.50. The names are the same in both cases.

OS ROM:

- `MOS (OS)` - OS ROM

Sideways ROMs:

- `DFS (9)` - for sideways ROM bank 9
- `Viewsheet (a)` - for sideways ROM bank A
- `Edit (b)` - for sideways ROM bank B
- `BASIC (c)` - for sideways ROM bank C
- `ADFS (d)` - for sideways ROM bank D
- `View (e)` - for sideways ROM bank E
- `Terminal (f)` - for sideways ROM bank F

## Master Compact

There are four sets of ROMs, for the four released versions of the OS:
MOS 5.00, MOS 5.10, MOS 5.11i and MOS I5.10C (Olivetti PC 128 S). The
names are the same in all cases.

OS ROM:

- `MOS (OS)` - OS ROM

Sideways ROMs:

- `ADFS (d)` - for sideways ROM bank D
- `BASIC (e)` - for sideways ROM bank E
- `UTILS (f)` - for sideways ROM bank F

For MOS 5.11i, there are two additional support ROMs that add Arabic
support:

- `MOS 5.11i ARABIC (usually 8)`
- `MOS 5.11i INTERNATIONAL (usually 2)`

The sideways ROM banks for these are just suggestions, reflecting the
standard setup.

## Electron

OS ROM:

- `Electron MOS` - OS ROM

Sideways ROMs:

- `Advanced Plus 1/Plus 6 ROM` - support ROM for the Plus 1
- `Plus 3 ADFS` - ADFS ROM for the Plus 3
